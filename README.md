# Editorial Longform Skill / Skill Dàn bài Longform

This package contains two equivalent localized skills:

- `editorial-longform-en/skill.md` — English instructions
- `editorial-longform-vi/skill.md` — Hướng dẫn tiếng Việt

Each skill includes the same reference HTML under `references/reference-longform.html`.

The skill is designed to transform long source material into a responsive editorial/e-magazine HTML experience built around 4–6 memorable ideas while preserving the source's factual meaning, qualifications, citations, and depth.
